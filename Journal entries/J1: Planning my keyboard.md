The model at changes

<br>
si the changes are as follows: 
1. removing the stagger in the leftmost and rightmost columns since the same finger as the second to end columns used them and caused uncomfortable reaches
2. increased column stagger for pink finger, and added fn ctrl and windows buttons to keep windows accessible using my keyboard
3. added 2 folds and abandoned the foldless flat design i was planning in favor of a more comfortable for the tilted design as seen in the below picture
<img width="710" height="616" alt="image" src="https://github.com/user-attachments/assets/6bac0909-b152-4f27-96d6-7a56c7da8ff4" />
4. shifted main keyboard one unit north of the thumb cluster to make it more natural for my hands (the crosses in the picture)
5. to accommodate the thumb cluster shift, the switches will not be supported by a pcb for the thumb cluster and wired directly to the main pcb via soldered wiring.
6. removing the numberline to keep it small in size
7. reducing the thumb cluster size to 4 keys
